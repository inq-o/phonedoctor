# UsageStats 실증 (2026-10-26)

증상 감지(ADR-0003 주 경로)의 전제를 재현 앱으로 확인한 기록. plan.md "증상 감지 설계"의 🔵 항목(분류 규칙)과 실패 조건을 여기서 정한다.

## 1. 환경

| 항목 | 값 |
|---|---|
| 기기 | 에뮬레이터 `Pixel_8_API_35` (Android 15, API 35), 스와이프 잠금, 시간대 Asia/Seoul |
| 재현 앱 | `testapps/bgad` — 알람(`setExactAndAllowWhileIdle`)마다 배경에서 광고 화면을 띄움. 띄운 시각을 logcat `BGAD SHOW`로 남겨 정답으로 씀 |
| 관찰 앱 | `testapps/usageprobe` — `PACKAGE_USAGE_STATS`로 `queryEvents` 덤프(E1~E3), 15분 주기 WorkManager 작업(E4) |
| 스크립트 | `testapps/poc/` — `e1.sh`·`e2.sh`·`e4.sh` 실행, `match.py`·`rule_v0.py`·`lag.py` 집계 |
| 원자료 | `ml/data/poc/` (레포 제외) |

## 2. E1 — 표시 방식별로 사용 기록에 남는가

광고 시각 ±2초 안에 `ACTIVITY_RESUMED`가 있으면 남은 것으로 셈.

| 방식 | 화면 | 남음 | 남은 이벤트 |
|---|---|---|---|
| ① 다른 앱 위 표시 권한으로 `startActivity` | 켜짐 | 10/10 | `ACTIVITY_RESUMED` (18~25ms 뒤) |
| ① | 꺼짐 | 5/5 | `ACTIVITY_PAUSED`, `ACTIVITY_RESUMED` |
| ② 전체 화면 알림 (`setFullScreenIntent`) | 켜짐 | 0/10 | `NOTIFICATION_INTERRUPTION`, `NOTIFICATION_SEEN`만 (헤드업 알림으로 뜸) |
| ② | 꺼짐 | 5/5 | `ACTIVITY_RESUMED` (약 270ms 뒤) |
| ③ 오버레이 창 (`TYPE_APPLICATION_OVERLAY`) | 켜짐 | 0/10 | 없음 |

- 액티비티형은 감지됨. 오버레이형은 사용 기록에 아무것도 안 남음 → FR-011 사전 경고로만 보조 (ADR-0003 전제와 같음).
- 전체 화면 알림은 화면이 켜져 있으면 헤드업 알림으로 바뀌어 화면 전환이 없음. 이 경우는 광고 화면이 아니라 알림이라 US10·알림 쪽 문제.

## 3. E2·E3 — 정상 전환과 광고를 가르는 규칙 v0

E2에서 정상 전환 8종을 10번씩 만들고(142개 `ACTIVITY_RESUMED`), E3에서 규칙을 적용함.

규칙 v0 (`testapps/poc/rule_v0.py`). 아래를 모두 만족하는 `ACTIVITY_RESUMED`만 광고로 셈.

| 코드 | 조건 |
|---|---|
| R1 | 시스템 앱이 아님 (`FLAG_SYSTEM`·`FLAG_UPDATED_SYSTEM_APP`). 설치된 앱 전체에서 판정하고, 목록에 없는 패키지는 사용자 앱으로 봄 (아이콘을 숨긴 앱도 셈) |
| R2 | 같은 앱 안 전환이 아님. 직전 `ACTIVITY_RESUMED`가 같은 앱이고, 그 뒤 화면이 꺼진 적 없고, 그 앱의 직전 `ACTIVITY_PAUSED`에서 2초 안이면 같은 앱 안 전환 |
| R3 | 직전 3초 안에 그 앱의 `USER_INTERACTION`(알림 탭 등)이 없음 |
| R4 | 화면 켜짐·잠금 해제 3초 안에, 화면이 꺼지기 전 보던 화면(같은 앱·같은 액티비티)으로 돌아온 게 아님 |
| R5 | 런처 아이콘이 여는 액티비티가 아님 (별칭이면 `ActivityInfo.targetActivity`로 풀어서 비교, 아이콘이 여러 개면 그중 하나) |

결과

| 시나리오 | 정상 전환 | 광고로 셈 (R1 켬) | 광고로 셈 (R1 끔) |
|---|---|---|---|
| 런처 아이콘 탭 | 11 | 0 | 4 (메시지 앱 첫 로그인 중간 화면) |
| 알림 탭 | 10 | 0 | 0 |
| 최근 앱에서 전환 | 10 | 0 | 0 |
| 앱에서 다른 앱 열기 | 20 | 0 | 0 |
| 화면 켜기 | 10 | 0 | 0 |
| 타이머 울림 (화면 꺼짐) | 30 | 0 | 20 (시계 10, 런처 10) |
| 전화 수신 (화면 꺼짐) | 31 | 0 | 30 (전화 10, 런처 20) |
| 앱 안 전면 광고 | 20 | 0 | 0 |
| **합계** | **142** | **0 (0%)** | **54 (38%)** |

광고: 화면 켜짐 ① 10/10, 화면 꺼짐 ① 5/5·② 5/5 모두 광고로 셈 (20/20).

- R1을 끄면 오탐이 거의 시스템 앱(런처·시계·전화)에서 나옴. 정상 앱 표본 대부분이 시스템 앱이라 R1이 오탐을 거의 다 막은 셈 → 사용자 설치 앱(카카오톡 등)의 정상 전환은 T074에서 따로 재야 함.
- 화면이 꺼진 상태의 광고는 `ACTIVITY_RESUMED`가 두 번 남을 수 있어 재현율은 이벤트가 아니라 광고 단위로 셈.
- R2·R4는 마지막 화면 꺼짐 시각과 직전 화면을 알아야 함 → 주기 작업 사이에 규칙 상태를 저장해야 함 (조회 창 앞쪽 60초만으로는 놓침).

## 4. E4 — 주기 작업이 광고를 얼마나 늦게 보는가

조건 하나를 걸고 40분 동안 광고 ①을 4분마다 10번 띄움. 관찰 앱 주기 작업(15분)이 각 광고를 처음 본 시각까지의 지연을 잼.

| 조건 | 설정 | 작업 실행 (시작 후 분) | 본 광고 | 지연 p50 / 최대 |
|---|---|---|---|---|
| 평소 | 화면 켜짐·충전 중 | 0, 16.1, 31.2 | 7/10 | 7.1 / 12.0분 |
| 화면 꺼짐 | 충전 중 | 0, 20.4, 38.4 | 9/10 | 8.3 / 16.3분 |
| Doze | 충전 해제 + `deviceidle force-idle` | 0, 15.2 | 3/10 | 7.0 / 11.0분 |
| 대기 버킷 rare | `am set-standby-bucket rare` | 0 | 0/10 | 40분 동안 실행 없음 |
| 강제 종료 | `am force-stop` | 0 | 0/10 | 작업 취소됨 |
| 권한 끔 | 사용 기록 접근 거부 | 0 (그 뒤 실패) | 0/10 | `queryEvents`가 `SecurityException` |

- 못 본 광고 중 평소·화면 꺼짐·Doze는 마지막 작업 뒤에 뜬 것(관찰 창이 끝나서 못 봄). 놓친 게 아님.
- 평소·화면 꺼짐은 NFR-02 목표(p95 ≤ 30분) 안. 실제 간격은 15~20분.
- Doze: 광고 자체는 Doze에서도 뜸(알람 면제). 작업은 25분 넘게 실행되지 않음. 에뮬레이터의 강제 Doze는 광고가 화면을 켜도 풀리지 않아 실제 기기보다 나쁜 쪽.
- rare: 40분 동안 한 번도 안 돎. rare 상태 기록은 40.6분에 1번 남았는데, 끝나고 버킷을 active로 되돌린 직후라 rare 측정에서 뺌.
- 강제 종료: WorkManager 작업이 같이 취소되고, 앱을 다시 열기 전까지 감지가 멈춤.
- 권한 끔: 예외로 작업이 실패함. 권한을 먼저 확인하고 꺼져 있으면 상태 보고(`DeviceStatus.protection.usageAccess=false`)만 해야 함.

측정 중 확인한 것

- 한 번도 열린 적 없는 앱은 대기 버킷이 NEVER(50)라 주기 작업 할당량이 0. 화면 없는 관찰 앱이 40분 동안 처음 1번만 돌았음(무효 자료 `ml/data/poc/e4_bucket_never/`). 그래서 실제 앱도 설정 마법사에서 화면이 한 번은 열려야 함. 측정에서는 시작 시 버킷을 active로 맞춤.

## 6. 한계

- 에뮬레이터만 씀. 갤럭시의 절전 앱·자동 최적화는 재지 않음.
- 정상 전환 표본이 시스템 앱 위주. 사용자 설치 앱의 정상 전환 오탐은 T074에서 잼.
- 재현 앱은 광고 SDK가 아니라 광고 화면을 흉내 낸 앱. 실제 애드웨어의 트램펄린·여러 단계 전환은 확인 안 함.
- 이벤트 보관 기간(E5)은 재지 않음. plan.md "조회"의 지원 최대 지연은 아직 미정.
- 조건마다 40분 1회씩. Doze·rare의 실제 지연 상한(점검 창 간격)은 재지 않음.
