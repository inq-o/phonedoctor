# 폰주치의 개인정보처리방침

시행일: 2026년 11월 18일 · 적용 판: 0.1.x

폰주치의(이하 "앱")는 휴대전화에서 사용자가 쓰지 않았는데 광고를 띄우는 앱을 찾아 알려 주는 앱입니다. 이 방침은 앱이 어떤 정보를 읽고, 어디에 두며, 얼마나 보관하는지 설명합니다.

## 1. 요약

- 앱은 **인터넷 권한이 없습니다.** 읽은 정보를 휴대전화 밖으로 보내지 않고, 개발자도 받지 않습니다.
- 회원가입, 로그인, 광고, 분석 도구가 없습니다.
- 앱이 만든 기록은 휴대전화 안에만 있고, 앱을 지우면 함께 지워집니다.

## 2. 읽는 정보와 이유

| 정보 | 필요한 권한 | 이유 |
|---|---|---|
| 설치된 앱 목록(앱 이름, 패키지 이름, 버전, 서명 인증서 지문, 시스템 앱 여부, 아이콘으로 여는 화면과 다른 앱이 열 수 있는 화면 이름) | 모든 앱 조회(`QUERY_ALL_PACKAGES`) | 광고를 띄운 앱이 어느 앱인지 가리고, 사용자가 직접 연 화면과 구분하기 위해 |
| 앱 화면 전환 기록(어느 앱의 어느 화면이 언제 열리고 닫혔는지, 화면 켜짐·잠금 해제 시각) | 사용 기록 보기(`PACKAGE_USAGE_STATS`, 사용자가 설정에서 직접 켬) | 사용자가 쓰지 않았는데 뜬 화면을 찾기 위해 |

앱은 사진, 문자, 연락처, 통화 기록, 위치, 화면 내용, 입력한 글자를 읽지 않습니다. 사용 기록에서도 화면 안의 내용은 볼 수 없고 앱과 화면 이름, 시각만 읽습니다.

## 3. 휴대전화 안에 남기는 기록과 보관 기간

| 기록 | 내용 | 보관 |
|---|---|---|
| 광고로 센 화면 전환 | 앱 패키지 이름·서명 지문·버전, 화면 이름, 시각 | 30일 뒤 자동 삭제 |
| 검사 기록 | 검사 시각, 결과, 센 전환 수 | 30일 뒤 자동 삭제 |
| 확인 요청 | 확인이 필요한 앱, 하루 횟수, 처리 상태(지움·정리됨 등) | 앱 데이터를 지울 때까지 |
| 판정 상태 | 다음 검사를 이어 하기 위한 값. 앱마다 최근에 다른 앱으로 넘어갈 때 보던 화면 이름 최대 8개 포함 | 다음 검사 때마다 바뀌며, 앱 데이터를 지울 때까지 |
| 설정 | 첫 설정을 마쳤는지 등 | 앱 데이터를 지울 때까지 |

- 이 기록은 휴대전화 백업(구글 클라우드 백업)과 기기 이전에서 빠지도록 설정되어 있습니다.
- 설정 > 애플리케이션 > 폰주치의 > 저장공간 > 데이터 삭제, 또는 앱 삭제로 언제든 모두 지울 수 있습니다.

## 4. 제3자 제공·처리 위탁

없습니다. 앱이 정보를 휴대전화 밖으로 보내지 않으므로 제3자에게 제공하거나 처리를 맡기는 일이 없습니다.

## 5. 앱 삭제 안내

확인이 필요한 앱을 지울 때 앱은 안드로이드의 앱 삭제 화면을 열 뿐이고, 사용자가 그 화면에서 직접 확인해야 지워집니다.

## 6. 아동

앱은 만 14세 미만 아동을 대상으로 하지 않으며, 나이를 묻거나 아동의 정보를 따로 처리하지 않습니다.

## 7. 바뀔 때

보호자 연결처럼 정보를 휴대전화 밖으로 보내는 기능을 더하면, 그 판을 내기 전에 이 방침을 고치고 앱 첫 화면 안내에서도 다시 알립니다. 고친 내용과 시행일은 이 문서에 남깁니다.
