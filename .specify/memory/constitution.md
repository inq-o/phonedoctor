- 버전 1.0.0 · 제정 2026-10-03

## I. 오탐 최소 우선

- 최우선 지표는 **오탐률(FPR) 5% 이하**. 탐지율·정확도보다 앞섬
- 근거: 할머니가 쓰던 정상 앱을 한 번이라도 막으면 가족 전체가 앱을 지움
- 판정 임계값은 검증셋에서 FPR 5%를 만족하는 지점으로 고정하고, 탐지율은 그 조건 아래에서 최대화

## II. 승인 경계 (Human-in-the-loop)

- **앱 삭제·정지 같은 파괴적 조치는 모델 단독으로 실행하지 않음**
- 기본 흐름: 모델 판정 → 보호자 승인 → 시니어 본인 확인 → 시스템 삭제 확인창
- 강력 모드(Device Owner)에서도 "정지(suspend)"까지만 자동화. "삭제"는 사람이 누름

## III. 데이터 최소화

- 기기 밖으로 나가는 데이터는 **위험 판정을 받은 앱의 정보만**
- 설치된 앱 전체 목록, 사용 기록 원본, 메시지·사진은 전송 금지
- 보호자는 시니어가 직접 연결을 승인해야 볼 수 있고, **시니어는 언제든 연결을 끊을 수 있음**

## IV. 온디바이스 우선

- 판정(특징 추출 + 추론)은 네트워크 없이 기기 안에서 끝남
- 서버는 승인 요청 중계와 모델 배포만 담당

## V. 스토어 정책 준수

- 핵심 기능을 AccessibilityService에 의존하지 않음 (Android 17 고급 보호 모드에서 자동 취소)
- 앱 아이콘 숨김·자기 보호(삭제 방해) 기능 없음 (강력 모드 제외, 강력 모드는 Device Owner 공식 경로)
- `QUERY_ALL_PACKAGES`·`isMonitoringTool` 선언과 실제 동작을 일치시킴

## VI. 시니어 접근성

- 시니어 화면은 **한 화면에 주요 행동 1개**
- 터치 영역 56dp 이상, 본문 20sp 이상, 시스템 글꼴 크기 200%에서 잘림 없음
- 색만으로 의미를 전달하지 않음 (색 + 아이콘 + 글자)
- 시간 제한이 있는 상호작용 금지

## VII. 측정 가능성

- 모든 판정은 로컬 로그로 남김(모델 버전, 점수, 근거 코드, 처리 결과)
- before/after 수치·실험 파라미터·환경은 사후 복원이 불가능하므로 실험 시점에 기록
- 평가용 테스트셋은 학습셋과 별도로 구축하고 학습에 쓰지 않음

## VIII. 널리 쓰는 구조

- 앱 구조는 [android/nowinandroid](https://github.com/android/nowinandroid) 관례를 기본값으로 따름
- 독자 구조를 쓰면 NiA와 무엇이 다른지 ADR로 남김
